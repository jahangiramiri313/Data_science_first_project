# Medical Disease & Patient Churn Analysis 🏥

## 📌 Project Overview
This project analyzes a medical dataset of 1,000 patient records to identify health trends and financial impacts. I performed data cleaning, exploratory analysis (EDA), and visualization to help healthcare providers understand patient behavior.

## 📊 What I did in this project:
* **Data Cleaning:** Handled 50+ missing values in columns like Age, Blood Pressure, and Treatment Cost using median and mode imputation.
* **EDA:** Grouped patients into age categories (e.g., 26-35, 46-60, 60+) to see which groups visit hospitals most often.
* **City Analysis:** Found that patients in **Lahore** have the highest average treatment costs (~110,959), while **Karachi** has the lowest (~97,101).
* **Disease Tracking:** Specifically tracked 95 patients in Karachi who suffer from Heart Disease.

## 🛠️ Tools Used
* **Python** (Pandas, NumPy)
* **Visualization:** Matplotlib, Seaborn
* **Environment:** Jupyter Notebook / Google Colab

## 🚀 How to use this
1. Download the `Medical_Disease_Analysis.ipynb` file.
2. Ensure you have the `Medical_dataset.csv` in the same folder.
3. Run the cells in a Jupyter environment to see the analysis.
